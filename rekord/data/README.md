# Daten

`words.txt.gz` – die je 50 000 häufigsten Wörter im Deutschen und Englischen, nach Häufigkeit sortiert (zusammengeführt,
kleingeschrieben). REKORD erkennt daran, welche Wörter in Unterlagen selten sind (Namen, Fachbegriffe) und welche Wörter im
Transkript echte Wörter sind (die es nicht „korrigiert“). Liegt in der App, wird nie aus dem Internet geladen.

Quelle: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) von Hermit Dave (2018, aus OpenSubtitles),
Inhalt lizenziert unter [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Diese Datei ist eine
Bearbeitung (gefiltert, zusammengeführt) und steht ebenfalls unter CC BY-SA 4.0.
